# gingertea 0.3.0

The terminal app now runs in Rust with Ratatui, retaining the tea themes, shaded
wordmark, media cards, keyboard shortcuts, and conversion dialogs.

- Native PyPI wheels support Windows x86-64, Linux x86-64, Apple Silicon Macs,
  and Intel Macs. Existing uv and pipx installs can upgrade to the Rust app.
- GitHub Releases include standalone executables and SHA-256 checksums.
- Playlist selection adds compact controls, select all, clear, invert, and a
  duration summary; playlist thumbnails have additional discovery fallbacks.
- Theme selection is alphabetized, previews selections, and restores the previous
  theme on cancel. Focus, footer spacing, and responsive layouts are refined.
- Event-driven motion stops when idle and can be disabled in Settings.
- Settings, history, and playlist archives use the existing platform directories.

Upgrade with `uv tool upgrade gingertea` or `pipx upgrade gingertea`, then run
`gingertea setup` to check the external media tools. The app continues to use
yt-dlp, FFmpeg/FFprobe, and Deno; optional native image tools replace Pillow codecs.

Each release must pass Rust formatting, warning-free Clippy, unit and real-media
tests, and an isolated Python-to-Rust wheel upgrade on each supported platform.
The retained Python reference suite also runs on Linux.
